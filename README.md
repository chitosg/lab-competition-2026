# 進化計算コンペティション2026

オリエンテーリングのコントロール選定問題を、遺伝的アルゴリズム（GA）で解くC++17プログラムです。

## 概要

以下の条件を満たすコースを探索します。

- 正門をスタート・ゴール地点とする
- 6〜12個のコントロールを選択する
- コントロール間の距離が近くなりすぎないようにする
- 推定所要時間を60分に近づける
- 累積登り高低差を50m以下に抑える
- 評価値 `E` を最小化する

## 使用技術

- C++17
- 遺伝的アルゴリズム
- ダイクストラ法
- 2-opt局所探索
- 最短経路・距離キャッシュ

## ディレクトリ構成

```text

├── evaluate.h/cpp     # route個体のデコード・目的関数・評価値計算
├── ga.h/cpp           # GAの個体生成・選択・交叉・突然変異・2-opt

│   ├── landmarks.csv
│   ├── nodes.csv

  ├── best_course.json       # 最良コース

```

## アルゴリズム

### 最短経路の事前計算

起動時に道路ネットワークを構築し、正門および全コントロール候補を起点としてダイクストラ法を実行します。

以下の値をキャッシュします。

- 道路上の最短距離
- 最短経路上の累積登り高低差
- コントロール候補間のユークリッド距離

GAの評価中はキャッシュを参照し、経路探索や距離計算を繰り返さない構成にしています。

### 個体表現

個体は、選択したコントロール候補のインデックスを訪問順に並べた配列で表します。

```text
[コントロール番号, コントロール番号, ...]
```

個体のコントロール数は必ず6〜12個です。

### 選択

トーナメント選択を使用します。

各世代では、評価値の優れた上位2個体を無条件に次世代へ引き継ぎます。

### 交叉

共通コントロールを必ず子個体へ引き継ぐ集合交叉を使用します。

- 両親に共通するコントロール：必ず継承
- 片方の親にのみ存在するコントロール：50%の確率で継承
- 個体サイズが6〜12個の範囲外になった場合：追加・削除で補正

### 突然変異

突然変異率は12%です。突然変異では、次のいずれかを実行します。

- 追加：未選択候補を1つ追加
- 削除：選択済み候補を1つ削除
- 置換：選択済み候補を未選択候補と交換

### 2-opt局所探索

交叉・突然変異後の個体に2-optを適用します。

正門発着の巡回順を入れ替えながら、距離と累積登りから計算した推定所要時間が改善する順序を探索します。

## 評価関数

評価値は次の重み付き和で計算します。

```text
E = 0.50 * f_map
  + 0.10 * f_dist
  + 0.25 * f_time
  + 0.15 * f_route
```

各目的関数の目標値は以下のとおりです。

| 項目 | 値 |
|---|---:|
| 最小コントロール数 | 6 |
| 最大コントロール数 | 12 |
| 目標コントロール数 | 8 |
| コントロール間の最低距離 | 150m |
| 目標所要時間 | 60分 |
| 平地歩行速度 | 4020m/h |
| 登り坂速度換算値 | 300m/h |
| 許容累積登り高低差 | 50m |

制約を満たさない個体や、経路が接続できない個体には大きなペナルティを与えます。

## 入力データ

### landmarks.csv

| 列 | 内容 |
|---|---|
| `id` | コントロール候補ID |
| `name` | 地点名 |
| `feature` | 地点種別 |
| `lat` | 緯度 |
| `lon` | 経度 |
| `nearest_node` | 最寄りの道路ノードID |

### nodes.csv

| 列 | 内容 |
|---|---|
| `node_id` | ノードID |
| `lat` | 緯度 |
| `lon` | 経度 |
| `elevation` | 標高 |

### edges.csv

| 列 | 内容 |
|---|---|
| `from_node` | 始点ノードID |
| `to_node` | 終点ノードID |
| `length_m` | 道路長 |
| `elevation_change` | 標高差 |
| `elevation_gain` | 累積登り |

### seimon.csv

正門の緯度・経度を記載します。先頭の有効な1行を使用します。

## ビルド方法

### Makefileを使用する場合

```bash
make
```

### g++を直接使用する場合

```bash
g++ -std=c++17 -O3 -Wall -Wextra \
    csv_loader.cpp graph.cpp evaluate.cpp ga.cpp main.cpp \
    -o orienteering
```

## 実行方法

```bash
make run
```

または、直接実行します。

```bash
./orienteering
```

Windowsの場合は次のように実行します。

```powershell
.\orienteering.exe
```

実行時の作業ディレクトリは、`input`フォルダを含むプロジェクトのルートディレクトリにしてください。

## 出力

実行後、`output/`に以下のファイルが生成されます。

### best_course.json

最良コースについて、次の情報を出力します。

- コントロール数
- 総距離
- 累積登り
- 推定所要時間
- 評価値
- 各目的関数の値
- 選択されたコントロール
- 道路ノード列

### fitness_history.csv

世代ごとの最良評価値を出力します。

```text
generation,best_fitness
1,...
2,...
...
```

## 再現性

乱数シードは `const.h` の `RANDOM_SEED` で設定しています。

同じ入力データと同じシードを使用した場合、同じ探索結果を再現できます。

## Windowsでの注意点

Visual Studioを使用する場合は、C++言語標準をC++17以上に設定してください。

また、実行時の作業ディレクトリは、`input`フォルダの親ディレクトリに設定してください。`input`フォルダそのものを作業ディレクトリにすると、`input/input/landmarks.csv`を参照してしまいます。

コンソールの日本語が文字化けする場合は、次のコマンドでUTF-8に変更できます。

```powershell
chcp 65001
```
